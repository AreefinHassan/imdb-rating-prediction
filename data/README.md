# Data

The IMDB data set is **not** committed to this repository — download it from its public source:

- **Dataset:** IMDB 5000 Movie Dataset (Kaggle)
- **URL:** https://www.kaggle.com/carolzhangdc/imdb-5000-movie-dataset
- **File:** `movie_metadata.csv` — 5,043 movies × 28 variables

The analysis in this project used the cleaned subset described in the report: USA movies only, missing values removed (3,015 movies, 16 predictors). No poster images are included here — the Kaggle page also lists poster files, which are large and are intentionally left out.
